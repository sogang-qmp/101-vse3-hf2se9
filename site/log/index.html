2026-07-01 — Same-code Δ cross-check; ΔH from isolated-molecule orbitals

Result. A VASP PBE single point on the vacuum molecule (same code and geometry as the B3LYP reference) isolates the pure exchange–correlation shift: $\Delta_\text{HOMO}$ = −0.58, $\Delta_\text{LUMO}$ = +0.17 eV, gap 0.001 → 0.751 eV. This is ≈0.42 eV smaller (near-rigid) than the vdW-DF2-referenced shift ($\Delta_\text{HOMO}$ = −1.01 eV); the offset mixes exchange–correlation and code (SIESTA vs VASP) differences and cannot be cleanly separated.

Decided. Keep the baseline at the functional the device transport actually uses: $\Delta_i = \varepsilon_i^\text{B3LYP} - \varepsilon_i^\text{vdW-DF2}$ (vacuum-aligned), applied as a relative scissor so the rigid code offset cancels.

Method. The $\Delta H$ projector uses the isolated-molecule MO coefficients, not an MPSH diagonalization of the in-device molecular block: Hf₂Se₉ is covalently fused into the VSe₃ chain, so the bare block carries no clean molecular levels near $E_F$ (valence manifold ~6 eV too deep, an 8 eV gap, empty $E_F$±2 eV window) — its $E_F$ weight is chain hybridization. $\Delta H = S\,C\,\mathrm{diag}(\Delta_i)\,C^\dagger S$ reproduces the earlier build to 10 meV.

Next. Recompute $T(E)$ with TBT.dH (corrected vs uncorrected); for the 9-cell run, build the projector from a device-geometry molecular single point (isolated↔device orientation registration).
