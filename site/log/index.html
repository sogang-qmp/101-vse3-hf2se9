분자 stacking. 고정 기하 스캔을 완료했다(rigid single-point). H 종단 gap 모드는 dimer·trimer 모두 $d$ = 3.5 Å에서 최소이며, 종단하지 않은 최소는 스캔 하한 2.5 Å이다. TEM 간격은 3.6 Å. → 09. Hf₂Se₉ 분자 stacking.

CNT encapsulation. 수렴한 VSe₃@(9,9) CNT의 $E_\mathrm{bind}$ = −4.854 eV/cell(−1.213 eV/f.u.). Hf₂Se₉@CNT는 force 수렴 전까지 최종 $E_\mathrm{bind}$는 예비값이다. → 10. CNT encapsulation 결합에너지.

구조 이완 재시작. CG 시험은 최대 힘이 dimer 0.506433, trimer 0.215633, Hf₂Se₉@CNT 0.361229 eV/Å로 상승해 중단했다. 이 궤적은 사용하지 않는다. 2026-07-29 backup DM/XV 상태에서 Broyden으로 재시작했으며 MaxDispl는 0.02 Å, 힘 수렴 기준은 0.02 eV/Å이다.

다음. 세 구조를 수렴시킨 뒤 2·3분자 conductance decay를 계산하고, Hf₂Se₉@CNT 결합에너지와 Δρ를 확정한다.

2026-07-18 — DFT+Σ v2 확정 · 방법론 점검 · eigenchannel 정정

  • 07-03 미팅 후속: I–V 비대칭은 window artifact → 대칭 window로 재적분, $I(-V)=-I(V)$(정류 없음). "gap 0.75 vs 0.2 eV" 불일치 해소: 0.75 eV는 고립분자 B3LYP gap(scissor 입력값), device frontier 간격은 분자–금속 hybridization으로 더 작음 — 서로 다른 양이라 분리 표기.
  • v2 보정: v1의 직접 B3LYP−vdW-DF2 뺄셈은 ~0.7 eV 코드 간 offset을 실어 비점유 준위 부호를 뒤집었음; v2는 공통 PBE 기준으로 각 코드 안에서만 빼서 → 점유↓/비점유↑, 고립 gap 0.75 eV, 보정 $T(E_F)$ 0.355 → 0.0032.

  • Eigenchannel 정정: v2 eigenchannel 에너지를 분자 frontier로 다시 선택(HOMO −0.325 / LUMO +0.355 eV; 이전 deep/2nd peak 오선택).

2026-07-03 — 그룹미팅: δH 보정 리뷰

결정

  1. 포말리즘 확인. δH는 molecule block에만 적용($\Delta H = S\,C\,\mathrm{diag}(\Delta)\,C^\dagger S$), SCF가 아니라 TBtrans 후처리 단계에서 transmission에 반영 → finite bias 재계산 불필요, zero-bias $T(E)$로 충분.
  2. 결과 접수. 보정 후 zero-bias transmission ~7× 감소, molecular PDOS에 보정이 깔끔히 반영 — 수치를 하나씩 검증한다는 전제에서 우리가 원하는 그림.

액션 아이템

  1. 보정 후 HOMO–LUMO gap 0.75 eV vs 그림상 ~0.2 eV 간격 불일치 추적 → 완료(07-06/15): 0.75 eV는 고립분자 B3LYP gap(scissor 입력값), device frontier 간격은 분자–금속 hybridization으로 더 작음 — 서로 다른 양으로 분리 표기.
  2. transmission 이상(on-resonance에서 낮음) 체크 → 진행: 방법론 점검에서 약결합 + $E_F$ pinning으로 귀속, 정량값은 상한·그림은 정성으로.
  3. I–V bias window 대칭성 + 그림/캡션 일치 → 완료(07-06): 대칭 window로 재적분, $I(-V)=-I(V)$(정류 없음).
  4. 발표자료에서 이해 못 한 문장 제거, 각 수치 출처 명시 → 진행(07-07/15): Darancet verbatim 인용 DFT+Σ 문서화 + 방법론 전면 점검.

2026-07-02 — 06-19 미팅 이후: 9-cell 수렴 → DFT+Σ 적용 → 3-way + 보정 I–V

1 · Scattering-region 길이 수렴

  • 전극당 VSe₃ 9 unit cells: $T(E_F)$ = 0.348 ≈ 0.354 (3 cells), 단일 채널 $\tau_0$ = 0.989 — 기하 구조·분자 PDOS·transmission 모두 7–9 cell에서 안정.

2 · DFT+Σ 분자준위 보정

  • 입력 (v2): $\Delta_i$를 공통 PBE 기준으로 각 코드 안에서만 빼서 구성 — $[\varepsilon^\text{B3LYP}-\varepsilon^\text{PBE}]_\text{VASP}+[\varepsilon^\text{PBE}-\varepsilon^\text{vdW-DF2}]_\text{SIESTA}$ — 점유는 내려가고 비점유는 올라가며 고립분자 gap이 0.75 eV로 열린다.
  • v1이 틀린 이유: B3LYP−vdW-DF2 직접 뺄셈에는 vacuum 정렬로 안 지워지는 ~0.7 eV 교차코드 offset(SIESTA vs VASP pseudopotential/basis)이 섞여 virtual shift 부호가 뒤집혔다; 공통 PBE·same-code 구성(v2)이 이를 제거한다.
  • Projector: 고립분자 MO (MPSH를 교차 확인용으로); 분자는 전극에 약한 반데르발스 접촉만 하는 독립 단위체다. $\Delta H = S\,C\,\mathrm{diag}(\Delta_i)\,C^\dagger S$, level-1 TBT.dH.
  • 적용 (9-cell): 보정된 $T(E)$는 분자 공명을 $E_F$에서 밀어내 Fermi 준위 transmission을 억제하며, 3-cell N25_k100 cross-check에도 그대로 전이된다.
  • Gap 확인: 고립분자 HOMO–LUMO gap이 0.02 → 0.75 eV로 열림 (B3LYP 목표값), DFT+Σ 문헌과 방향 일치.

3 · 3-way transmission + 보정 I–V

  • Disconnected 완료: $T(E_F)$ = 0.000 → pristine 0.70 / hetero 0.348 / disconnected 0 — 분자가 유일한 전도 다리.
  • 보정 Landauer I–V (zero-bias $T(E)$, 대칭 window): 보정이 저바이어스 전류를 누른다; 곡선은 홀함수 $I(-V)=-I(V)$ (정류 없음 — 이전 비대칭 window figure는 2026-07-05 정정).
