2026-07-18 — DFT+Σ v2 finalized · method audit · eigenchannel fix

  • 07-03 meeting follow-up: the I–V asymmetry was a window artifact → re-integrated with a symmetric window, $I(-V)=-I(V)$ (no rectification). The "gap 0.75 vs 0.2 eV" mismatch is resolved: 0.75 eV is the isolated-molecule B3LYP gap (the scissor input); the device frontier split is smaller because the molecule hybridizes with the metal — distinct quantities, now labelled separately.
  • v2 correction: v1's direct B3LYP−vdW-DF2 subtraction carried a ~0.7 eV cross-code offset (which flipped the virtual-level sign); v2 subtracts within each code through a common PBE reference → occupied down / virtual up, isolated gap 0.75 eV, corrected $T(E_F)$ 0.355 → 0.0032.
  • Method audit (Darancet NL 2012, read in full): standard "DFT+Σ" = Σ¹ (gas-phase gap) + Σ² (image charge); ours is Σ¹-only → more precisely a gas-phase gap correction, results quoted as an upper bound / qualitative. The gas-phase term should be a ΔSCF total-energy IP/EA. Image charge on a 1D chain is not quantitative — a cylindrical estimate spans 0.6–3.2 eV (5× model dependence).
  • Eigenchannel fixed: the v2 eigenchannel energies were re-picked at the molecular frontier (HOMO −0.325 / LUMO +0.355 eV; the earlier deep/2nd peaks were mislabelled).

2026-07-02 — Since the 06-19 meeting: 9-cell convergence → DFT+Σ applied → 3-way + corrected I–V

  • 9 VSe₃ unit cells per electrode: $T(E_F)$ = 0.348 ≈ 0.354 (3 cells), a single dominant channel — geometry, molecular PDOS, transmission all stable by 7–9 cells.

2 · DFT+Σ molecular-level correction

  • Inputs (v2): $\Delta_i$ built by same-code subtraction through a common PBE reference, $[\varepsilon^\text{B3LYP}-\varepsilon^\text{PBE}]_\text{VASP}+[\varepsilon^\text{PBE}-\varepsilon^\text{vdW-DF2}]_\text{SIESTA}$ — occupied shift down, virtual up; isolated-molecule gap opens to 0.75 eV.
  • Why v1 failed: a direct B3LYP−vdW-DF2 subtraction carries a ~0.7 eV cross-code offset (SIESTA vs VASP pseudopotential/basis) that vacuum alignment does not remove, so the virtual shift came out with the wrong sign; the common-PBE, same-code construction (v2) removes it.
  • Projector: isolated-molecule MOs (with MPSH as a cross-check); the molecule is a discrete unit only weakly, van-der-Waals-bound to the electrodes. $\Delta H = S\,C\,\mathrm{diag}(\Delta_i)\,C^\dagger S$, level-1 TBT.dH.
  • Applied (9-cell): the corrected $T(E)$ moves the molecular resonance off $E_F$ and suppresses the Fermi-level transmission; the correction transfers directly to the 3-cell N25_k100 cross-check.
  • Gap check: the isolated-molecule HOMO–LUMO gap opens 0.02 → 0.75 eV (the B3LYP target), consistent with the DFT+Σ literature.
