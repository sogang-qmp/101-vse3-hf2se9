Iterations

지난 회차 보관 — 사이드바 별도 섹션, 최신순

연구는 여러 회차(iteration)를 돈다. 지금 회차는 루트(Plan · Methods · Results)에 있고, 끝난 회차는 여기에 보관한다. 각 회차는 자기 폴더 iterNNN/ 안에 개요(index) + 작업별 서브페이지로 들어간다 (메인 섹션이 하위 페이지를 갖는 것과 동일).

iterations/
  iter002/
    index.html        이 회차 개요 (목표 · 결과 · 이어진 것)
    t01-…/  t02-…/    회차 안의 작업들 — 각각 하위 페이지
  iter001/  …

새 회차 시작하는 법

  1. 루트의 plan/ methods/ results/를 iterations/iterNNN/로 이동(동결). 작업이 여럿이면 iterNNN/index.html(개요) + t01-…/ t02-…/(작업별 서브페이지)로 쪼갠다.
  2. 각 회차 index.html에 <meta name="order" content="-NN"> — 최신 회차가 위로 오게.
  3. 루트에서 새로 시작 — 처음부터든, 지난 회차에서 쓸 것만 가져오든. 각 회차는 자기완결(지난 회차를 가리키지 말고 그 회차만 봐도 이해되게).
  4. python3 gen-tree.py — 사이드바 갱신.

(아직 보관된 회차 없음. 실제 예시: sogang-qmp/128-gd2c-trap.)
