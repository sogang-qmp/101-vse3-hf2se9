Previous calculations review (archive)

Source: reports/previous-calculations/previous-calculations.md (dated 2026-03-16).

Goal

Summarize the ~1-year-old VSe₃/Hf₂Se₉ calculations preserved in two archive directories (101_VSe3-Hf2Se9/, VSe3-Hf2Se9/) to identify what is reusable for the current project. Across VASP (MD, hybrid DFT), SIESTA (band/PDOS, transport), and Quantum ESPRESSO (functional comparison), the prior work covered Hf₂Se₉ molecule/chain stability, electronic structure, optical properties, and transport — but the core goal, a 1D molecule junction, was left incomplete because the Hf-doped molecule structure was unstable.

Result — what was computed

  • Hf₂Se₉ single molecule: VASP MD (NVT 300 K, up to 500 steps) confirmed molecular stability; SIESTA PBE band + PDOS near EF.
  • Hf₂Se₉ chain: VASP MD (up to 1000 steps), SIESTA PBE+Grimme band + PDOS.
  • VSe₃–Hf₂Se₉ heterostructure (V₂₀Se₇₂Hf₂, 94 atoms): VASP MD, SIESTA band/PDOS, Hubbard-U test, CNT+Hf₂Se₉ structure, Mulliken charge analysis.
  • Transport: TranSIESTA + TBtrans I-V curve over 7 voltage points (0.00–0.30 V) for a 20-unit-cell Hf₂Se₉ molecular junction (k = 1×1×4, electronic temperature 400 K).
  • Optical (hybrid): B3LYP (VASP) neutral and e-doped completed; HSE06 and PBE/LDA optical comparisons left incomplete (empty directories).
  • Code comparison: SIESTA (LDA/PBE) vs QE (LDA/PBE/B3LYP) for the same structure.
  • Auxiliary VSe3-Hf2Se9/: single chains, molecule, heterojunction (separation + angle tests), Hf-doped VSe₃ chain, NbSe₃ comparison system, and a 3-system transport set (Hf₂Se₉ / Hf-doped / VSe₃).

Mulliken charge analysis of the heterojunction: Hf atoms gain electrons (Hf1 −0.27e, Hf2 −0.15e); interface V atoms hold ~0.2e more than bulk V — significant interfacial charge transfer.

Discussion — incomplete / failed

  • Hf-doped molecule structure: unstable, did not converge → to be retried with CNT-confined MD.
  • HSE06 calculations: directories created but never run.
  • PBE/LDA optical comparison: not done.
  • VSe₃ TP vs TAP: not done at the time → the core task of the current project.
