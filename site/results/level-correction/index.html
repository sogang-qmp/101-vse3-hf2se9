Goal

Two things before the level-corrected transport: (1) confirm the conductance is converged once the scattering region (the central device between the two semi-infinite VSe₃ electrodes) is made longer, and (2) compute the B3LYP→vdW-DF2 molecular-orbital energy shifts $\Delta_i$ that feed the DFT+Σ correction.

B. B3LYP molecular-level correction (DFT+Σ) — inputs

vdW-DF2, a non-hybrid functional, underestimates the isolated molecule's HOMO–LUMO gap, so the transmission resonance sits too close to $E_F$. The correction is a DFT+Σ (DFT plus a self-energy $\Sigma$) level alignment: each molecular orbital $i$ is rigidly shifted by $\Delta_i$ — the gap-opening shift from the transport functional to an accurate hybrid — and the shift is added to the device Hamiltonian as

$\displaystyle \Delta H = S\,C\,\mathrm{diag}(\Delta_i)\,C^{\dagger}\,S,$

with $S$ the overlap and $C$ the isolated-molecule MO coefficients. The H-terminated Hf₂Se₉ is a discrete unit that meets each VSe₃ electrode through a weak, van-der-Waals-range contact (Se···chain ≈ 3.6 Å), so its isolated-molecule orbitals are a clean, well-defined projector basis (the in-device MPSH projector is built in parallel as a cross-check; construction detail in Methods: DFT+Σ). The device transport uses vdW-DF2 throughout, so the corrected levels stay referenced to the same functional. The target shifts $\Delta_i$ come from the molecular-orbital energies in an accurate hybrid (B3LYP) versus the transport functional (vdW-DF2); because B3LYP is available only in VASP and vdW-DF2 only in SIESTA, combining them into a physical $\Delta_i$ is the crux — worked out in Section C.

C. DFT+Σ molecular-level correction

The molecular frontier levels are shifted by a scissor operator applied only to the Hf₂Se₉ block, non-self-consistently at the TBtrans stage ($\Delta H = S\,C\,\mathrm{diag}(\Delta_i)\,C^\dagger S$; see Methods · DFT+Σ). The shift $\Delta_i=\varepsilon_i^{\text{B3LYP}}-\varepsilon_i^{\text{vdW-DF2}}$ is where the difficulty lies — B3LYP is only available in VASP, vdW-DF2 in SIESTA.

1. First attempt (v1) — and why it was wrong

v1 built $\Delta_i$ by subtracting the two codes directly, aligned by vacuum level, and reported device $T(E_F)$ 0.355→0.051 with a "frontier gap 0.18 eV". These were the meeting figures:

Why it is wrong. The two codes carry a ~0.71 eV rigid offset that vacuum alignment does not remove (a same-PBE test gives +0.71 eV uniformly across all orbitals; even the explicit valence-electron count differs, SIESTA 168 vs VASP 74). The offset pushes every B3LYP level down, so at the vdW-DF2 frontier energy (−5.55, ≈$E_F$) the B3LYP level that lands there is not the HOMO (−6.59, far below) but the virtual LUMO+3/LUMO+4:

The two B3LYP levels straddling $E_F$ are LUMO+4 (−5.494) and LUMO+3 (−5.679), spacing 0.185 eV — exactly the v1 "0.18". So the v1 "gap" was never a HOMO–LUMO gap; it was two mis-aligned virtual levels dragged onto $E_F$. The true isolated-molecule gap is 0.75 eV. This is the direct disproof of the v1 result.

2. Fix (v2) — subtract within each code (common PBE reference)

Subtract only within each code, inserting a common PBE reference so the code offset cancels inside each bracket (one extra SIESTA-PBE single point supplies the second bracket):

$\displaystyle \Delta_i^{v2}=[\varepsilon^{\text{B3LYP}}-\varepsilon^{\text{PBE}}]_{\text{VASP}}+[\varepsilon^{\text{PBE}}-\varepsilon^{\text{vdW-DF2}}]_{\text{SIESTA}}$

The signs become physical — occupied levels shift down, virtual levels up — and the isolated-molecule HOMO–LUMO gap opens to 0.75 eV. Applied to the 9-cell device, the v2 correction suppresses $T(E_F)$ from 0.348 (uncorrected) to 0.0032.

Discussion / next

δH insertion path (implementation check): the correction enters through TBtrans's documented built-in hook — $H \leftarrow H + \delta H$, where TBT.dH is the fdf flag for a NetCDF file holding $\delta H$ and sisl's write_delta writes that level-1 static file. No SIESTA source patch is needed; our task is only to construct the molecular projector matrix $\Delta H = S\,C\,\mathrm{diag}(\Delta_i)\,C^\dagger S$ and write it as deltaH.dH.nc.
