DFT+Σ via TBtrans δH — implementation

2026-06-19 · method · How the molecular-level correction enters the transport calculation, and why no SIESTA source patch is needed

Summary

The B3LYP→vdW-DF2 level correction is a DFT+Σ scissor shift. It does not require editing SIESTA/TBtrans source — TBtrans has a built-in δH (delta-H) mechanism that adds a correction matrix to the input Hamiltonian at read time. We build $\Delta H$ with sisl, write it to a .dH.nc file, and point TBtrans at it with TBT.dH.

Why the correction is needed

Non-hybrid functionals (PBE/vdW-DF2) carry a self-interaction/delocalization error: occupied levels sit too high, virtual too low, so the HOMO–LUMO gap is underestimated (our molecule: vdW-DF2 0.02 eV vs B3LYP 0.75 eV). In off-resonant tunnelling the linear conductance follows a single-level Lorentzian

$\displaystyle T(E)=\frac{\Gamma_L\,\Gamma_R}{(E-\varepsilon_0)^2+[(\Gamma_L+\Gamma_R)/2]^2},$

so the level offset $|\varepsilon_0-E_F|$ governs $T(E_F)$. A gap squeezed onto $E_F$ inflates conductance. DFT+Σ shifts each molecular level by $\Delta_i=\varepsilon_i^{\text{B3LYP}}-\varepsilon_i^{\text{vdW-DF2}}$ to restore the offset — the quasiparticle self-energy $\Sigma$ approximated as a per-orbital constant (scissor). Because $\Delta_i$ is energy-independent, the static self-energy equals a Hamiltonian correction:

$\displaystyle G(E)=\big[(E+i\eta)S-(H+\Delta H)-\Sigma_L-\Sigma_R\big]^{-1}, \qquad \Delta\Sigma(E)=\Delta H=\text{const.}$

Hence TBtrans level-1 δH (no $E$/$k$ dependence) is exactly the right tool; for $T(E)$ the δH and δΣ paths are identical (they differ only in bond/orbital currents).

Correction value — same-code subtraction via a common PBE (v2)

We want $\Delta_i=\varepsilon_i^{\text{B3LYP}}-\varepsilon_i^{\text{vdW-DF2}}$ on the device (SIESTA) footing, but B3LYP is only available in VASP. Subtracting the two codes directly injects a code offset (v1's failure). Instead, insert a common PBE reference and subtract only within each code:

$\displaystyle \Delta_i^{v2}=\underbrace{\big[\varepsilon_i^{\text{B3LYP}}-\varepsilon_i^{\text{PBE}}\big]_{\text{VASP}}}_{\text{same code}}+\underbrace{\big[\varepsilon_i^{\text{PBE}}-\varepsilon_i^{\text{vdW-DF2}}\big]_{\text{SIESTA}}}_{\text{same code}}$

Each bracket is a same-code subtraction, so the code-dependent basis/pseudopotential offset cancels inside each term; the intermediate PBE drops out, leaving $B3LYP-vdW\text{-}DF2$ free of the cross-code artifact. This required one extra SIESTA-PBE single point on the vacuum molecule (identical to the vdW-DF2 run except XC) to measure the second bracket (+0.23 eV, uniform across frontier).

When & how it enters the calculation

Timing — post-SCF, non-self-consistent. The correction is applied after the device vdW-DF2 SCF has converged; the SCF is not re-run. Structure and bonding stay at their vdW-DF2 values — only the molecular level positions move. The flow:

  1. device DFT (TranSIESTA) → $H$, $S$ (trans.TSHS)
  2. add ΔH to the molecular block: $H\to H+\Delta H$
  3. TBtrans Green's function with the corrected Hamiltonian: $G(E)=[(E+i\eta)S-(H+\Delta H)-\Sigma_L-\Sigma_R]^{-1}$
  4. corrected transmission $T(E)=\mathrm{Tr}[\Gamma_L\,G\,\Gamma_R\,G^\dagger]$

The ΔH matrix — step-by-step derivation (non-orthogonal basis)

① Correction operator. Shift each molecular orbital $\phi_i$ by $\Delta_i$ — a scissor projector. Only the level position moves; the internal hopping (wavefunction shape) and the electrode coupling $\Gamma$ stay at their vdW-DF2 values:

$\displaystyle \Delta\hat H = \sum_i \Delta_i\,|\phi_i\rangle\langle\phi_i|$

② Expand the MO over atomic orbitals (PAO): $|\phi_i\rangle=\sum_\mu C^i_\mu|\chi_\mu\rangle$, where the $C^i_\mu$ are the molecular-orbital coefficients (STEP 2) and $\chi_\mu$ the atomic orbitals.

③ Take matrix elements in the PAO basis:

$\displaystyle (\Delta H)_{\mu\nu}=\langle\chi_\mu|\Delta\hat H|\chi_\nu\rangle =\sum_i\Delta_i\,\langle\chi_\mu|\phi_i\rangle\,\langle\phi_i|\chi_\nu\rangle.$

④ Where the overlap $S$ enters — the step that is easy to drop. The PAOs are non-orthogonal, $\langle\chi_\mu|\chi_\lambda\rangle=S_{\mu\lambda}\neq\delta_{\mu\lambda}$, so

$\displaystyle \langle\chi_\mu|\phi_i\rangle=\sum_\lambda C^i_\lambda\,S_{\mu\lambda}=(S\,C^i)_\mu.$

Substituting into ③ gives the working form:

$\displaystyle \boxed{\;\Delta H = S\,C\,\mathrm{diag}(\Delta_i)\,C^{\dagger}\,S\;}$

In an orthogonal basis ($S=I$) this reduces to the textbook $\sum_i\Delta_i c_i c_i^\dagger$ — the $S$ on both sides is precisely the non-orthogonal correction.

⑤ Verify the levels move by exactly $\Delta_j$. With the generalized eigenproblem $Hc_j=\varepsilon_j Sc_j$ and $S$-orthonormality $C^\dagger SC=I$ (hence $C^\dagger Sc_j=e_j$, the $j$-th unit vector):

$\displaystyle (H+\Delta H)c_j=\varepsilon_j Sc_j + S\,C\,\mathrm{diag}(\Delta)\,e_j=(\varepsilon_j+\Delta_j)\,Sc_j.$

The eigenvector $c_j$ is unchanged and the eigenvalue moves $\varepsilon_j\to\varepsilon_j+\Delta_j$ — exactly the intended shift. Adding to a single onsite element $H_{\mu\mu}$ alone does not achieve this in a non-orthogonal basis (verified in sisl #129), which is why $S$ must sit on both sides.

Projector: isolated-molecule MO, cross-checked against MPSH. The usual robust route diagonalises the in-device molecular block (MPSH), which auto-normalises $C$. Here the H-terminated Hf₂Se₉ is a discrete unit bound to each VSe₃ electrode only through a weak, van-der-Waals-range contact, so its isolated (vacuum) orbitals are already a clean, well-defined molecular basis. We build the projector from the isolated (vacuum) molecule MO coefficients (the same molecule/geometry used for $\Delta_i$), register them into the device basis, and rescale to $C^\dagger S_\text{dev} C = I$; the in-device MPSH construction is carried out in parallel as a cross-check:

import sisl, numpy as np

H   = sisl.get_sile('device.TSHS').read_hamiltonian()
S   = H.Sk(format='array').real               # device overlap
mol = np.load('mol_orbital_idx.npy')          # Hf2Se9 PAO indices in the device
SM  = S[np.ix_(mol, mol)]

# MO coefficients from the ISOLATED vacuum-molecule SIESTA run (STEP 2) — NOT an
# MPSH diagonalization of the in-device block (built separately as a cross-check)
C     = np.load('mo_coeff_isolated.npy')      # (n_mol_orb, n_MO), same geometry as Δ_i
delta = np.load('delta_i.npy')                # eV, per orbital, |ε − E_F| ≲ 2 eV window

# register into the device basis: rescale so Cᵀ S_dev C = I
norm = np.einsum('mi,mn,ni->i', C.conj(), SM, C).real
C    = C / np.sqrt(norm)

dH_block = SM @ C @ np.diag(delta) @ C.conj().T @ SM    # S C diag(Δ) Cᵀ S
dH = H.copy(); dH.empty(); dH.set_nsc([1,1,1])          # molecule closed in unit cell
for a, mu in enumerate(mol):
    for b, nu in enumerate(mol):
        dH[mu, nu] = dH_block[a, b]
sisl.get_sile('deltaH.dH.nc', 'w').write_delta(dH)      # no k=/E= → level-1

Both constructions are sanctioned by the original implementation. Montes & Vázquez (Appl. Sci. 11, 802 (2021), Eq. (1)) build Σ either from a separate calculation of the relaxed isolated molecule or from the junction-cropped molecular subspace (MPSH) — the isolated-molecule projector is a standard route, not a workaround (full text verified 2026-07-02).

The isolated-molecule build reproduces the earlier attempt to ~10 meV. (For the 9-cell run the projector should come from a molecular single point at the device geometry, with isolated↔device orientation registration.)

Pitfalls

  • Supercell (non-square submatrix). A .TSHS packs supercell couplings into one matrix, so slicing the molecule block can give a non-square array. Close the molecule inside the unit cell with H.set_nsc([1,1,1]) — the manual states Bloch "phases are only added on super-cell elements, not unit-cell elements", so a unit-cell block needs no phase correction. Never diagonalise the 27 supercell blocks separately.
  • Non-orthogonal ΔH ($S$ on both sides). Adding a bare onsite term (H[i,i] += …) does not move the generalized eigenvalue ($H\psi=\varepsilon S\psi$) as intended (sisl #129). Use $\Delta H = S\,C\,\mathrm{diag}(\Delta_i)\,C^\dagger S$; the orthogonal limit $S=I$ recovers the textbook form.
  • Post-check (gate before recomputing T). After applying ΔH, confirm the molecular PDOS / MPSH peaks actually moved by $\Delta_i$. A mismatch means a missing $S$, bad normalization, or an index-mapping error.

How δH actually enters — per (E,k), verified from source

The table above is the what; this is the how, read from the sisl delta source and the TBtrans reference (2026-07-01) so the level-1 choice is not taken on faith.

  • The file carries a "level" tag. sisl write_delta tags the matrix by which arguments are present (_get_lvl_k_E): level-1 = no E or k dependence, level-2 = k, level-3 = E, level-4 = both. We call write_delta(dH) with no k=/E= → level-1, one constant matrix. That is exactly the static-self-energy scissor $\Delta\Sigma(E)=\Delta H=\text{const}$ — choosing level-1 is the scissor approximation.
  • It enters inside the Green's-function inverse, at every (E,k). sisl's class docstring gives $H'(k)=H(k)+\delta H(E,k)+\delta\Sigma(E,k)$; TBtrans forms $G(E,k)=\big[(E+i\eta)S(k)-H(k)-\delta H-\Sigma_L(E,k)-\Sigma_R(E,k)\big]^{-1}$ at each energy / k-point. Because our term is level-1, the same $\delta H$ is added at every (E,k) (a level-4 term would take precedence where its grid matches).
  • δH vs δΣ: identical in $G$, $T(E)$, and DOS; they differ only in bond/orbital currents (δΣ excluded). We use δH so orbital currents stay physical.
  • Why set_nsc([1,1,1]): TBtrans "add[s] the phases on all elements of δ" but only on super-cell elements. Closing the molecule block inside the unit cell leaves no super-cell element, so no Bloch phase $e^{ik\cdot R}$ is wrongly applied to $\delta H$ (otherwise one must pre-multiply δ by the negative phase).

Precedent & how ours differs

The direct precedent for STEP 3 (adding Σ to the molecular Hamiltonian via the MPSH block) is Montes & Vázquez (2021) and Fallaque et al. (2022) — both correct DFT-overestimated molecular-junction conductance to experiment, and both sanction building the projector either from a separate isolated-molecule calculation or from the junction-cropped (MPSH) subspace (annotated in References below). How ours differs (stated honestly): both precedents are organic molecule + Au; no direct precedent for an inorganic 1D chain (VSe₃) electrode was found. Our shift is the B3LYP−vdW-DF2 KS difference rather than the standard ΔSCF IP/EA, and we omit the image-charge term that both papers include.
