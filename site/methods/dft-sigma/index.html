DFT+Σ via TBtrans δH — 구현

2026-06-19 · method · molecular-level 보정이 transport 계산에 어떻게 들어가는지, 그리고 왜 SIESTA source patch가 필요 없는지

요약

B3LYP→vdW-DF2 준위 보정은 DFT+Σ scissor shift이다. SIESTA/TBtrans source를 편집할 필요가 없다 — TBtrans에는 읽어들이는 시점에 input Hamiltonian에 보정 행렬을 더해주는 내장 δH (delta-H) mechanism이 있다. $\Delta H$를 sisl로 build하여 .dH.nc 파일에 쓰고, TBT.dH로 TBtrans가 그것을 가리키도록 한다.

보정이 필요한 이유

비-하이브리드 functional(PBE/vdW-DF2)은 self-interaction error를 갖는다: occupied 준위는 너무 높고 virtual은 너무 낮아, HOMO–LUMO gap이 과소평가된다(우리 분자: vdW-DF2 0.02 eV vs B3LYP 0.75 eV). Off-resonant tunneling에서 linear conductance는 single-level Lorentzian을 따른다

$\displaystyle T(E)=\frac{\Gamma_L\,\Gamma_R}{(E-\varepsilon_0)^2+[(\Gamma_L+\Gamma_R)/2]^2},$

따라서 준위 offset $|\varepsilon_0-E_F|$가 $T(E_F)$를 지배한다. gap이 $E_F$에 밀착되면 conductance가 부풀려진다. DFT+Σ는 각 분자 준위를 $\Delta_i=\varepsilon_i^{\text{B3LYP}}-\varepsilon_i^{\text{vdW-DF2}}$만큼 이동시켜 offset을 회복한다 — quasiparticle self-energy $\Sigma$를 per-orbital 상수(scissor)로 근사한다. $\Delta_i$가 energy-independent이므로, static self-energy는 Hamiltonian 보정과 같아진다:

$\displaystyle G(E)=\big[(E+i\eta)S-(H+\Delta H)-\Sigma_L-\Sigma_R\big]^{-1}, \qquad \Delta\Sigma(E)=\Delta H=\text{const.}$

따라서 TBtrans level-1 δH($E$/$k$ 의존성 없음)가 바로 딱 맞는 도구다; $T(E)$의 경우 δH와 δΣ 경로는 동일하다(bond/orbital current에서만 차이가 난다).

2026-07-08 정정 (v2). 첫 시도(v1)는 $\Delta_i=\varepsilon_i(\text{B3LYP, VASP})-\varepsilon_i(\text{vdW-DF2, SIESTA})$를 서로 다른 코드 값의 직접 뺄셈으로 계산했다. vacuum 정렬로도 코드 간 잔여 offset(HOMO ~0.69 eV)이 제거되지 않는다 — 이 offset이 진짜 virtual shift (~0.2 eV)보다 커서 모든 virtual $\Delta$의 부호를 뒤집었고(LUMO~LUMO+4 전부 $<0$), gap이 열리지 않고 분자가 과충전됐다. "relative scissor라 코드 offset이 상쇄된다"던 서술은 틀렸다. v2는 PBE를 공통 기준으로 각 코드 안에서만 빼서 offset을 제거한다(아래).

보정값 — 공통 PBE 기준으로 각 코드 안에서만 뺌 (v2)

우리가 원하는 것은 device(SIESTA) 기준의 $\Delta_i=\varepsilon_i^{\text{B3LYP}}-\varepsilon_i^{\text{vdW-DF2}}$이지만 B3LYP는 VASP에만 있다. 두 코드를 직접 빼면 코드 offset이 섞인다(v1 실패). 대신 공통 PBE 기준을 끼워 각 코드 안에서만 뺀다:

$\displaystyle \Delta_i^{v2}=\underbrace{\big[\varepsilon_i^{\text{B3LYP}}-\varepsilon_i^{\text{PBE}}\big]_{\text{VASP}}}_{\text{같은 코드}}+\underbrace{\big[\varepsilon_i^{\text{PBE}}-\varepsilon_i^{\text{vdW-DF2}}\big]_{\text{SIESTA}}}_{\text{같은 코드}}$

각 괄호가 같은 코드 안 뺄셈이라 코드 의존 basis/pseudopotential offset이 항마다 자체 상쇄된다. 중간 PBE가 소거되어 형식상 $B3LYP-vdW\text{-}DF2$가 되지만 코드 아티팩트는 섞이지 않는다. 둘째 항 측정을 위해 진공 분자에 SIESTA-PBE single point 1개(vdW-DF2 계산과 XC만 다르고 나머지 동일)를 추가했다(+0.23 eV, frontier 전역 균일).

언제 & 어떻게 계산에 들어가는가

시점 — post-SCF, non-self-consistent. 보정은 device vdW-DF2 SCF가 수렴한 이후에 적용되며; SCF는 재실행하지 않는다. 구조와 결합은 vdW-DF2 값에 그대로 머문다 — 분자 준위 위치만 이동한다. 흐름:

  1. device DFT (TranSIESTA) → $H$, $S$ (trans.TSHS)
  2. 분자 block에 ΔH를 더함: $H\to H+\Delta H$
  3. 보정된 Hamiltonian으로 TBtrans Green's function: $G(E)=[(E+i\eta)S-(H+\Delta H)-\Sigma_L-\Sigma_R]^{-1}$
  4. 보정된 transmission $T(E)=\mathrm{Tr}[\Gamma_L\,G\,\Gamma_R\,G^\dagger]$

ΔH 행렬 — 단계별 유도(non-orthogonal basis)

① 보정 연산자. 각 molecular orbital $\phi_i$를 $\Delta_i$만큼 이동시킨다 — scissor projector. 준위 위치만 이동하고; 내부 hopping(wavefunction 모양)과 전극 coupling $\Gamma$는 vdW-DF2 값에 머문다:

$\displaystyle \Delta\hat H = \sum_i \Delta_i\,|\phi_i\rangle\langle\phi_i|$

② MO를 atomic orbital (PAO)로 전개: $|\phi_i\rangle=\sum_\mu C^i_\mu|\chi_\mu\rangle$, 여기서 $C^i_\mu$는 molecular-orbital coefficient(STEP 2)이고 $\chi_\mu$는 atomic orbital이다.

③ PAO basis에서 matrix element를 취함:

$\displaystyle (\Delta H)_{\mu\nu}=\langle\chi_\mu|\Delta\hat H|\chi_\nu\rangle =\sum_i\Delta_i\,\langle\chi_\mu|\phi_i\rangle\,\langle\phi_i|\chi_\nu\rangle.$

④ overlap $S$가 들어가는 지점 — 빠뜨리기 쉬운 단계. PAO는 non-orthogonal이므로, $\langle\chi_\mu|\chi_\lambda\rangle=S_{\mu\lambda}\neq\delta_{\mu\lambda}$, 따라서

$\displaystyle \langle\chi_\mu|\phi_i\rangle=\sum_\lambda C^i_\lambda\,S_{\mu\lambda}=(S\,C^i)_\mu.$

이를 ③에 대입하면 실제 사용 형태가 된다:

$\displaystyle \boxed{\;\Delta H = S\,C\,\mathrm{diag}(\Delta_i)\,C^{\dagger}\,S\;}$

orthogonal basis($S=I$)에서 이것은 교과서적 $\sum_i\Delta_i c_i c_i^\dagger$로 환원된다 — 양쪽의 $S$가 바로 non-orthogonal 보정이다.

⑤ 준위가 정확히 $\Delta_j$만큼 이동함을 검증. generalized eigenproblem $Hc_j=\varepsilon_j Sc_j$와 $S$-orthonormality $C^\dagger SC=I$(따라서 $C^\dagger Sc_j=e_j$, $j$번째 unit vector)를 사용하면:

$\displaystyle (H+\Delta H)c_j=\varepsilon_j Sc_j + S\,C\,\mathrm{diag}(\Delta)\,e_j=(\varepsilon_j+\Delta_j)\,Sc_j.$

eigenvector $c_j$는 변하지 않고 eigenvalue는 $\varepsilon_j\to\varepsilon_j+\Delta_j$로 이동한다 — 정확히 의도한 shift이다. 단일 onsite element $H_{\mu\mu}$에만 더하는 것은 non-orthogonal basis에서 이를 달성하지 못한다 (sisl #129에서 검증), 그래서 $S$가 양쪽에 있어야 한다.

Projector: 고립분자 MO, MPSH와 교차 확인. 통상적인 견고한 경로는 in-device 분자 block을 diagonalize(MPSH — Molecular Projected self-consistent Hamiltonian)해 $C$를 자동 정규화한다. 그러나 여기서는 H-terminated Hf₂Se₉가 각 VSe₃ 전극과 약한 반데르발스 거리로만 결합한 독립 단위체라, 그 고립(진공) 오비탈이 이미 깨끗한 분자 기저다. 그래서 projector를 고립(진공) 분자 MO 계수($\Delta_i$에 쓴 것과 같은 분자/구조)에서 만들고, device basis에 등록한 뒤 $C^\dagger S_\text{dev} C = I$로 rescale한다; in-device MPSH 구성은 교차 확인용으로 병행한다:

import sisl, numpy as np

H   = sisl.get_sile('device.TSHS').read_hamiltonian()
S   = H.Sk(format='array').real               # device overlap
mol = np.load('mol_orbital_idx.npy')          # Hf2Se9 PAO indices in the device
SM  = S[np.ix_(mol, mol)]

# 고립 진공-분자 SIESTA 계산(STEP 2)의 MO 계수 — in-device block의 MPSH
# diagonalization이 아님(MPSH는 교차 확인용으로 별도 구성)
C     = np.load('mo_coeff_isolated.npy')      # (n_mol_orb, n_MO), Δ_i와 동일 구조
delta = np.load('delta_i.npy')                # eV, per orbital, |ε − E_F| ≲ 2 eV window

# device basis에 등록: Cᵀ S_dev C = I 되도록 rescale
norm = np.einsum('mi,mn,ni->i', C.conj(), SM, C).real
C    = C / np.sqrt(norm)

dH_block = SM @ C @ np.diag(delta) @ C.conj().T @ SM    # S C diag(Δ) Cᵀ S
dH = H.copy(); dH.empty(); dH.set_nsc([1,1,1])          # molecule closed in unit cell
for a, mu in enumerate(mol):
    for b, nu in enumerate(mol):
        dH[mu, nu] = dH_block[a, b]
sisl.get_sile('deltaH.dH.nc', 'w').write_delta(dH)     # no k=/E= → level-1

두 구성 모두 원 구현에서 인정된다. Montes & Vázquez (Appl. Sci. 11, 802 (2021), Eq. (1))는 Σ를 완화된 고립분자의 별도 계산 또는 junction에서 잘라낸 분자 부분공간(MPSH) 어느 쪽에서도 만든다 — 고립분자 projector는 우회가 아니라 표준 경로다(원문 확인 2026-07-02).

고립분자 구성은 이전 시도를 ~10 meV까지 재현한다. (9-cell 계산에서는 projector를 device 구조에서의 분자 single point로부터 얻고, 고립↔device 방향 정렬을 맞춰야 한다.)

TBtrans input

TBT.dH deltaH.dH.nc

TBtrans stdout에 δH 파일을 읽었다는 로그가 있는지 확인한다. $T(E)$ 비교에서는 TBT.dH와 TBT.dSE가 동일한 결과를 준다.

Pitfall

  • Supercell (non-square submatrix). .TSHS는 supercell coupling을 하나의 행렬에 담으므로, 분자 block을 잘라내면 non-square 배열이 나올 수 있다. H.set_nsc([1,1,1])로 분자를 unit cell 안에 닫는다 — 매뉴얼은 Bloch "phases are only added on super-cell elements, not unit-cell elements"라고 명시하므로, unit-cell block에는 phase 보정이 필요 없다. 27개 supercell block을 따로 diagonalize하지 말 것.
  • Non-orthogonal ΔH ($S$ 양쪽). 맨몸 onsite 항 (H[i,i] += …)을 더하는 것은 generalized eigenvalue ($H\psi=\varepsilon S\psi$)를 의도대로 이동시키지 못한다(sisl #129). $\Delta H = S\,C\,\mathrm{diag}(\Delta_i)\,C^\dagger S$를 사용한다; orthogonal 극한 $S=I$가 교과서 형태를 회복한다.
  • Post-check (T 재계산 전 gate). ΔH를 적용한 뒤, 분자 PDOS / MPSH peak이 실제로 $\Delta_i$만큼 이동했는지 확인한다. 불일치는 $S$ 누락, 잘못된 normalization, 또는 index-mapping 오류를 뜻한다.

δH가 실제로 어떻게 들어가나 — (E,k)마다, 소스로 검증

위 표가 무엇이라면, 이건 어떻게다 — level-1 선택을 믿음이 아니라 sisl delta 소스와 TBtrans reference(2026-07-01 직접 열람)로 확인했다.

  • 파일은 "level" 태그를 갖는다. sisl write_delta는 어떤 인자가 주어졌는지로 행렬에 level을 매긴다 (_get_lvl_k_E): level-1 = E·k 의존 없음, level-2 = k, level-3 = E, level-4 = 둘 다. 우리는 write_delta(dH)를 k=·E= 없이 호출 → level-1, 상수 행렬 하나. 이것이 static self-energy scissor $\Delta\Sigma(E)=\Delta H=\text{const}$와 정확히 대응 — level-1을 쓴 것 자체가 scissor 근사다.
  • 그린 함수 역행렬 안, 매 (E,k)에서 들어간다. sisl class docstring: $H'(k)=H(k)+\delta H(E,k)+\delta\Sigma(E,k)$; TBtrans는 각 에너지·k점에서 $G(E,k)=\big[(E+i\eta)S(k)-H(k)-\delta H-\Sigma_L(E,k)-\Sigma_R(E,k)\big]^{-1}$ 를 만든다. 우리 항은 level-1이라 모든 (E,k)에서 같은 $\delta H$가 더해진다 (level-4 항이 있으면 그 격자가 맞는 곳에서 우선).
  • δH vs δΣ: $G$·$T(E)$·DOS에는 동일; bond/orbital current에서만 갈린다 (δΣ 제외). 우리는 orbital current까지 물리적으로 맞도록 δH를 쓴다.
  • 왜 set_nsc([1,1,1])인가: TBtrans는 "δ의 모든 원소에 phase를 더한다"지만 super-cell 원소에만 붙는다. 분자 블록을 unit cell 안에 닫으면 super-cell 원소가 없어 $\delta H$에 Bloch phase $e^{ik\cdot R}$가 잘못 붙지 않는다 (안 닫으면 δ에 음의 phase를 곱해 상쇄해야 함).

선례 & 우리 방식의 차이

STEP 3(분자 Hamiltonian에 Σ를 더하는 것)의 직접 선례는 Montes & Vázquez (2021)와 Fallaque et al. (2022) — 둘 다 DFT가 과대평가한 molecular-junction conductance를 실험 수준으로 보정하고, projector를 고립분자 별도 계산 또는 junction에서 crop한 (MPSH) subspace 어느 쪽에서 만들어도 됨을 공인한다(아래 References에 주석). 우리 방식의 차이(솔직히): 두 선례 모두 organic molecule + Au이며 inorganic 1D chain (VSe₃) 전극에 대한 직접 선례는 찾지 못했다. 우리 shift은 표준 ΔSCF IP/EA가 아니라 B3LYP−vdW-DF2 KS 차이이며, 두 논문이 포함하는 image-charge 항을 생략한다.
